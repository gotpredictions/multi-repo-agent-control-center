3. **It's actually yours to give.** You represent that the contribution is your own original work,

4. **No expectation of inclusion or compensation.** Signed Off is not obligated to review, merge,

If you don't agree to these terms, please don't submit a contribution — you're still welcome to
use the software for any permitted purpose under [LICENSE](LICENSE).

## How to indicate agreement

Include a line at the end of your pull request description or commit message: `I agree to the
Contributor Terms in CONTRIBUTING.md.` A maintainer should not merge a contribution without it.

(PolyForm Strict) and standard contributor-assignment practice, but neither has been reviewed by
